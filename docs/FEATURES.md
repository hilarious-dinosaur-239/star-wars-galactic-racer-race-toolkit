# Star Wars Galactic Racer Race Toolkit — feature reference

Star Wars Galactic Racer Race Toolkit focuses on three connected areas: vehicle groups, control profiles, race notes. Its organization keeps frequently used options close to the context they belong to.

| Section | Description |
|---|---|
| Vehicle groups | A dedicated section for vehicle groups and the configuration details associated with that area. |
| Control profiles | Related settings collected into named groups for a clearer configuration workflow. |
| Race notes | A dedicated section for race notes and the configuration details associated with that area. |

The project page follows the same section structure.
